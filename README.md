# EduBoard AI

An AI-powered interactive learning workspace designed for curious minds.

## Current prototype

- Responsive learning dashboard
- Tutor AI conversation interface (demo UI; real AI responses require a secure backend)
- Interactive whiteboard with touch and mouse drawing
- Question image upload and preview (AI image analysis is not connected yet)
- Personal notes saved in the browser

## Run locally

Open `index.html` in a modern browser.

## Publish with GitHub Pages

1. Open **Settings** in this repository.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.

Expected site address:
`https://amsyaramran.github.io/eduboard-ai/`

## Project files

- `index.html` — page structure
- `style.css` — responsive visual design
- `script.js` — navigation and browser-side interactions

## Security

Never place AI provider API keys in frontend JavaScript. Real AI features must be connected through a secure backend.
